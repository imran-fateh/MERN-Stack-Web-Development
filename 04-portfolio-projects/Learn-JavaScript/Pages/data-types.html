Data Types & Strings

Learn how JavaScript represents different kinds of values and understand primitive data types, type checking, strings, and template literals.

01 — Foundation

What Are Data Types?

A data type describes what kind of value a piece of data represents. JavaScript uses data types to understand how different values should behave.

For example, 25 represents a number, while "Hello" represents a string.

Why Data Types Matter

Knowing the type of a value helps you predict how JavaScript will handle it in calculations, comparisons, conditions, and application logic.

02 — Classification

Primitive & Non-Primitive Data Types

JavaScript data types can broadly be understood as primitive and non-primitive values.

Primitive

Primitive values represent a single value. Common primitive types include Number, String, Boolean, Undefined, Null, Symbol, and BigInt.

Non-Primitive

Non-primitive values can represent collections or more complex structures. Objects and arrays are common examples.

Coming Later

Objects and arrays will be explored in depth in their dedicated topics. For now, remember the basic distinction.

03 — Type Checking

The typeof Operator

The typeof operator helps us determine the data type of a value.

Example 
let age = 23;

console.log(typeof age);
Output "number"

The result tells us that the value stored in age is a number.

04 — Primitive Type

Number

The Number type is used for numeric values, including positive numbers, negative numbers, integers, and decimal values.

Number Example 
let age = 23;
let price = 499.99;
let temperature = -5;

console.log(typeof price);
Output "number"
05 — Primitive Type

String

A String represents text. JavaScript strings can be written using single quotes, double quotes, or template literals.

String Example 
let firstName = "Imran";
let language = 'JavaScript';

console.log(typeof firstName);
Output "string"
Remember

Text inside quotes is treated as a string, even when the characters look like numbers.

06 — Logical Value

Boolean

A Boolean represents one of two logical values: true or false.

Boolean values are especially important when JavaScript makes decisions, such as checking whether a user is logged in or whether a condition is satisfied.

Boolean Example 
let isLoggedIn = true;

console.log(typeof isLoggedIn);
Output "boolean"
Used Heavily Later

Boolean values become especially important when we learn comparisons, conditions, and control flow.

07 — Special Value

Undefined

undefined means a value has not been assigned to a variable yet.

Undefined Example 
let userName;

console.log(userName);
console.log(typeof userName);
Output 
undefined
"undefined"
08 — Intentional Empty Value

Null

null represents an intentional absence of a value. A developer can explicitly assign null when there is currently no value.

Null Example 
let selectedProduct = null;

console.log(selectedProduct);
Output null
JavaScript Quirk

typeof null returns "object". This is a historical behavior in JavaScript that you should remember.

09 — Primitive Type

Symbol

A Symbol creates a unique primitive value. Symbols are useful when a unique identifier is needed.

Symbol Example 
let firstId = Symbol("id");
let secondId = Symbol("id");

console.log(firstId === secondId);
Output false

Even when two Symbols contain the same description, each Symbol is unique.

10 — Large Integers

BigInt

BigInt is used for integers that are too large to be safely represented by the regular Number type.

BigInt Example 
let largeNumber = 9007199254740993n;

console.log(typeof largeNumber);
Output "bigint"
Important

BigInt values are written with an n suffix and should not be casually mixed with regular Number values.

11 — Working With Text

String Concatenation

String concatenation means joining strings together. JavaScript commonly uses the + operator for this purpose.

Concatenation Example 
let firstName = "Imran";
let lastName = "Fateh";

let fullName = firstName + " " + lastName;

console.log(fullName);
Output Imran Fateh
Notice the Difference

The + operator can perform arithmetic with numbers and concatenation when strings are involved.

12 — Modern Strings

Template Literals

Template literals provide a convenient way to create strings and insert values directly into them.

They use backticks and expressions inside ${...}.

Template Literal Example 
let firstName = "Imran";
let lastName = "Fateh";

console.log(`My name is ${firstName} ${lastName}.`);
Output My name is Imran Fateh.
Developer Advantage

Template literals are often easier to read than long strings joined with multiple + operators.

13 — Real Development

Practical Example: User Profile

In a real application, different data types commonly work together. A user profile may contain text, numbers, and Boolean values at the same time.

Practical Example 
let userName = "Imran";
let userAge = 23;
let isStudent = true;

console.log(
  `Name: ${userName}, Age: ${userAge}, Student: ${isStudent}`
);
Result

Output

Console Output Name: Imran, Age: 23, Student: true

This example shows how different JavaScript data types can be combined to represent real application information.

Key Takeaways

Important Notes

  • Data types describe the kind of value JavaScript is working with.
  • Primitive values represent individual values.
  • Objects and arrays are examples of non-primitive values.
  • typeof can be used to inspect the type of a value.
  • Strings represent text and can be written with quotes.
  • Boolean values are either true or false.
  • undefined usually represents an unassigned value.
  • null represents an intentional absence of a value.
  • Every Symbol is unique.
  • BigInt is designed for very large integers.
  • Template literals make dynamic strings easier to read.
Avoid These

Common Mistakes

Confusing Number and String

25 is a Number, while "25" is a String because the second value is inside quotes.

Assuming null is undefined

undefined and null are different concepts. One commonly represents an unassigned value, while the other represents an intentional empty value.

Forgetting the backticks

Template literals require backticks. Regular quotes do not provide the same interpolation syntax.

Expecting typeof null to return null

JavaScript returns "object" for typeof null. This is a historical JavaScript behavior.

Quick Revision

Quick Revision

  • Number: numeric values.
  • String: text values.
  • Boolean: true or false.
  • Undefined: value has not been assigned.
  • Null: intentional absence of a value.
  • Symbol: unique primitive value.
  • BigInt: very large integers.
  • typeof helps identify a value's type.
  • Template literals use backticks and ${...}.
