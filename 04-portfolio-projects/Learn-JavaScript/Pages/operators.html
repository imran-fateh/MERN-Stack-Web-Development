Operators & Expressions

Learn how JavaScript uses operators and operands to create expressions, perform calculations, assign values, and change stored values.

What Are Operators?

Operators are special symbols used to perform operations on values and variables in JavaScript. They allow you to calculate, compare, assign, modify, and combine values.

Common operators include arithmetic operators such as +, -, *, and /, as well as assignment operators such as =.

Operands & Expressions

An operand is a value or variable that an operator works on. An expression is a combination of values, variables, and operators that produces a result.

01 Operand

A value or variable used by an operator.

02 Operator

A symbol that performs an operation.

03 Expression

A combination that produces a value.

JavaScript 
let result = 10 + 5;

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations with numbers.

+ Addition

Adds two values together.

- Subtraction

Subtracts the second value from the first.

* Multiplication

Multiplies two values.

/ Division

Divides one value by another.

% Remainder

Returns the remainder after division.

** Exponentiation

Raises a value to a power.

Assignment Operators

Assignment operators store a value in a variable. The basic assignment operator is =.

JavaScript 
let score = 100;
score = 150;

Compound Assignment

Compound assignment operators combine an arithmetic operation with assignment. They provide a shorter way to update an existing variable.

JavaScript 
let score = 10;

score += 5;
score *= 2;
Tip

Compound assignment is useful when you repeatedly update a stored value.

Increment & Decrement

The increment operator ++ increases a value by one, while the decrement operator -- decreases a value by one.

JavaScript 
let count = 5;

count++;
count--;

Prefix & Postfix

Increment and decrement operators can be placed before or after a variable. The position determines whether the value is changed before or after the expression is evaluated.

Prefix

JavaScript 
let value = 5;
let result = ++value;

The value is increased first, then used in the expression.

Postfix

JavaScript 
let value = 5;
let result = value++;

The current value is used first, then increased.

Operator Precedence

Operator precedence determines the order in which JavaScript evaluates operators in an expression.

JavaScript 
let result = 10 + 5 * 2;
Output 20
Important

Multiplication is evaluated before addition in this expression. Use parentheses when you want to make the intended order explicit.

Practical Example

Operators are commonly used when calculating prices, totals, scores, quantities, counters, and other values in real applications.

Real-World Example

A shopping cart can use multiplication to calculate the price of multiple items and addition to calculate the final total.

JavaScript 
const price = 500;
const quantity = 3;
const total = price * quantity;

console.log(total);

Output

The previous example calculates the total price by multiplying the price of one item by the quantity.

Output 1500

Important Notes

  • Operators perform operations on operands.
  • An expression produces a value.
  • The = operator assigns a value; it does not compare values.
  • Compound assignment operators update existing values.
  • Prefix and postfix increment/decrement can produce different expression results.
  • Parentheses can make the intended evaluation order clear.

Common Mistakes

Confusing = with comparison

The = operator assigns a value. It is not the same as a comparison operator.

Ignoring prefix and postfix behavior

value++ and ++value do not always produce the same expression result.

Forgetting operator precedence

Different operators can be evaluated in a specific order. Use parentheses when the order matters.

Quick Revision

Operators perform actions on operands, while expressions combine values and operators to produce a result. Remember arithmetic, assignment, increment/decrement, and operator precedence as the core foundations of this topic.
