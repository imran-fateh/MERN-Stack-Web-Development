Variables & User Input

Learn how JavaScript stores and manages values using variables, how var, let, and const behave, and how to receive basic input from users.

What Is a Variable?

A variable is a named place used to store a value so that the program can use that value later. Instead of repeatedly writing the same data, we give it a meaningful name and work with that name.

Simple Idea

Think of a variable like a labeled box. The label is the variable name, and the value inside the box is the stored data.

Key Idea

A variable gives your program a reusable name for a value.

Variable Declaration & Initialization

Declaring a variable means creating it with a variable keyword. Initialization means giving that variable its first value.

01 Declaration

Create the variable.

02 Initialization

Give the variable its first value.

03 Use the Value

Use the variable throughout your code.

JavaScript 
let userName = "Imran";

console.log(userName);
Output Imran

The var Keyword

var is the older way of declaring variables in JavaScript. A variable declared with var can be redeclared and reassigned.

JavaScript 
var userName = "Imran";

var userName = "Fateh";

console.log(userName);
Output Fateh
Important

var allows redeclaration. Modern JavaScript generally prefers let and const when their behavior is more appropriate.

The let Keyword

let is used when a variable's value may need to change later. A variable declared with let cannot be redeclared in the same scope, but its value can be reassigned.

JavaScript 
let score = 50;

score = 80;

console.log(score);
Output 80

The const Keyword

const is used when a variable should not be reassigned after its initial value has been assigned.

JavaScript 
const courseName = "JavaScript";

console.log(courseName);
Important

A const variable must receive its initial value when it is declared, and that binding cannot later be reassigned.

Reassignment

Reassignment means giving an already declared variable a new value. This is possible with let and var.

JavaScript 
let age = 22;

age = 23;

console.log(age);
Output 23

Redeclaration

Redeclaration means declaring the same variable name again. The behavior depends on the keyword used.

var

var allows redeclaration in the same scope.

JavaScript 
var name = "Imran";
var name = "Fateh";

let

let does not allow redeclaration in the same scope.

JavaScript 
let name = "Imran";
// let name = "Fateh";
Remember

Redeclaration and reassignment are not the same thing. Redeclaration creates the declaration again; reassignment changes the existing value.

Variable Naming

Meaningful variable names make JavaScript code easier to understand and maintain.

  • Use letters, digits, underscore _, or dollar sign $.
  • A variable name should not begin with a digit.
  • JavaScript variable names are case-sensitive.
  • Do not use reserved JavaScript keywords as variable names.
  • Prefer descriptive names such as userName instead of unclear names such as x.
JavaScript 
let firstName = "Imran";
let userAge = 23;

User Input

JavaScript can receive simple input from a user through the browser's prompt() function. The browser displays a dialog where the user can enter a value.

JavaScript 
let userName = prompt("Please enter your name");

console.log(userName);
Important

The value received from prompt() is treated as user input. Converting input into numbers is a separate concept that will be developed further when type conversion is covered.

Practical Example

Variables become useful when a program needs to store information and use it later. A simple registration or profile form can collect a user's name and display it back to them.

Real-World Example

A website can ask for a visitor's name and then use that stored value to create a personalized message.

JavaScript 
let userName = prompt("Please enter your name");

console.log("Welcome " + userName);

Output

If the user enters Imran, the program stores that value in the variable and uses it in the message.

Output Welcome Imran

Important Notes

  • A variable stores a value under a meaningful name.
  • Declaration creates a variable, while initialization gives it its first value.
  • var allows redeclaration and reassignment.
  • let allows reassignment but not redeclaration in the same scope.
  • const must be initialized when declared and cannot be reassigned.
  • Redeclaration and reassignment are two different operations.
  • prompt() can be used for simple browser-based user input.

Common Mistakes

Confusing declaration with initialization

Declaring a variable and assigning its first value are related but separate concepts.

Redeclaring a let variable

A let variable cannot be declared again in the same scope.

Trying to reassign const

A const binding cannot be assigned a new value after its initialization.

Using unclear variable names

Names such as userName and studentMarks make code easier to understand than generic names such as a or x.

Quick Revision

Variables let JavaScript store and reuse values. Remember the difference between declaration, initialization, reassignment, and redeclaration. Use let when a value may change, const when reassignment is not needed, and understand var as the older variable declaration approach.
