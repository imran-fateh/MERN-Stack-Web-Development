Day 08 Focus

Display Property in Practice

Different display values help control how elements behave and how layouts are created.

Inline

Useful for text-level elements that remain within the normal text flow.

Block

Elements take available horizontal space and normally begin on a new line.

Inline Block

Keeps elements on the same line while allowing width and height control.

Flex

Provides flexible one-dimensional alignment and spacing control.

Grid

Creates structured row and column based layouts.
